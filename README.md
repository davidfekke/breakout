# A breakout style game with Three.js

## Controls

- **Touch:** drag anywhere on the screen to move the paddle, tap to start.
- **Mouse:** move to steer, click to start.
- **Keyboard:** arrow keys / A-D to move, Space to start or restart.

The playfield keeps its 4:3 proportions on any screen (phones, tablets, ultrawide
monitors) and the physics are frame-rate independent, so gameplay is the same at
60 Hz and 120 Hz. Landscape gives the biggest playfield on phones.
